PHOTOS — drop your real A3S photos in THIS folder
==================================================

The presentation looks for the files below. Until a file is here, that
slide shows a placeholder (or, for the closing backdrop, simply stays a
solid color). Add a file with the matching name and it appears on refresh.

Use landscape (wide) photos where possible. JPG or PNG both work; if you
use PNG, keep the .jpg name OR update the filename in index.html / config.js.

CLOSING-SLIDE PHOTO BACKDROP (the carousel)
-------------------------------------------
The final slide crossfades through a set of community photos behind the ask.
EASIEST: name them  carousel-1.jpg, carousel-2.jpg, carousel-3.jpg ...  and
drop them here. They load automatically, in order, up to 40 (gaps are OK).

Prefer to choose the order or reuse other filenames? List them in config.js
under window.CAROUSEL instead.

Tip: these sit behind a dark overlay with text on the left, so photos with
faces/action toward the RIGHT or CENTER read best. ~24 is a great number.

TIPS
----
- Faces and genuine expressions matter more than image quality.
- Get permission before showing recognizable faces, especially minors.
- Web hosting (GitHub Pages) is case-sensitive: gamenight-1.jpg, not .JPG.

(Earlier versions referenced "vision.jpg" — that slide now uses an
illustration, so vision.jpg is no longer used.)
